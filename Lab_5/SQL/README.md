# Query 1 - Customers from India

## Description

This query displays all customers whose country is India.

## SQL Query

```sql
Select *
From Customer
Where Country = 'India';
```

## Explanation

- `SELECT *` selects all columns.
- `FROM Customer` uses the `Customer` table.
- `WHERE Country = 'India'` filters the records and returns only customers from India.

# Query 2 - 10 Most Expensive Tracks

## Description

This query displays the 10 tracks with the highest unit price.

## SQL Query

```sql
Select Name, UnitPrice
From Track
Order By UnitPrice Desc
Limit 10;
```

## Explanation

- `SELECT Name, UnitPrice` displays the track name and its price.
- `FROM Track` uses the `Track` table.
- `ORDER BY UnitPrice DESC` sorts the tracks from highest price to lowest price.
- `LIMIT 10` displays only the first 10 records.

# Query 3 - Total Revenue by Country

## Description

This query calculates the total revenue generated by each country.

## SQL Query

```sql
Select Customer.Country,
       Sum(Invoice.Total) As TotalRevenue
From Customer
Join Invoice
On Customer.CustomerId = Invoice.CustomerId
Group By Customer.Country
Order By TotalRevenue Desc;
```

## Explanation

- `Customer.Country` selects the country.
- `SUM(Invoice.Total)` calculates the total revenue.
- `JOIN` combines the `Customer` and `Invoice` tables.
- `Customer.CustomerId = Invoice.CustomerId` matches customers with their invoices.
- `GROUP BY Customer.Country` creates a separate group for each country.
- `ORDER BY TotalRevenue DESC` sorts countries from highest revenue to lowest revenue.

## Join Used

This query uses an **INNER JOIN**.

# Query 4 - 10 Best-Selling Tracks

## Description

This query displays the 10 tracks with the highest total quantity sold.

## SQL Query

```sql
Select Track.Name,
       Sum(InvoiceLine.Quantity) As TotalSold
From InvoiceLine
Join Track
On InvoiceLine.TrackId = Track.TrackId
Group By Track.TrackId
Order By TotalSold Desc
Limit 10;
```

## Explanation

- `Track.Name` displays the track name.
- `SUM(InvoiceLine.Quantity)` calculates the total quantity sold for each track.
- `InvoiceLine` contains the quantity sold for each invoice line.
- `JOIN Track` connects the sales information with the track names.
- `InvoiceLine.TrackId = Track.TrackId` matches each invoice line with its track.
- `GROUP BY Track.TrackId` creates one group for each track.
- `ORDER BY TotalSold DESC` sorts tracks from highest sales to lowest sales.
- `LIMIT 10` displays only the top 10 tracks.

## Join Used

This query uses an **INNER JOIN**.

# Query 5 - Monthly Revenue for 2009

## Description

This query calculates the total revenue for each month of the year 2009.

## SQL Query

```sql
Select StrfTime('%m', InvoiceDate) As Month,
       Sum(Total) As Revenue
From Invoice
Where StrfTime('%Y', InvoiceDate) = '2009'
Group By Month
Order By Month;
```

## Explanation

- `InvoiceDate` contains the complete invoice date.
- `strftime('%Y', InvoiceDate)` extracts the year from the date.
- `WHERE strftime('%Y', InvoiceDate) = '2009'` filters only invoices from 2009.
- `strftime('%m', InvoiceDate)` extracts the month from the invoice date.
- `SUM(Total)` calculates the total revenue.
- `GROUP BY Month` groups invoices according to their month.
- `ORDER BY Month` displays the months in order.

# SQL Concepts Used

## 1. SELECT

Used to select the required columns from a table.

Example:

```sql
Select Name, UnitPrice
From Track;
```

---

## 2. WHERE

Used to filter records based on a condition.

Example:

```sql
Where Country = 'India';
```

---

## 3. SUM

Used to calculate the total of numeric values.

Example:

```sql
Sum(Total)
```

---

## 4. JOIN

Used to combine data from two related tables.

Example:

```sql
Join Invoice
On Customer.CustomerId = Invoice.CustomerId
```

---

## 5. GROUP BY

Used to create groups of records based on a column.

Example:

```sql
Group By Customer.Country
```

---

## 6. ORDER BY

Used to sort the result.

Example:

```sql
Order By TotalRevenue Desc;
```

`DESC` means descending order, from highest to lowest.

---

## 7. LIMIT

Used to restrict the number of rows returned.

Example:

```sql
Limit 10;
```

This returns only 10 records.

---

## 8. SQLite strftime()

The `strftime()` function is used to extract parts of a date.

### Extract Year

```sql
strftime('%Y', InvoiceDate)
```

This extracts the year from the complete date.

For example:

```text
2009-01-15 → 2009
2010-05-20 → 2010
```

### Extract Month

```sql
strftime('%m', InvoiceDate)
```

This extracts the month from the complete date.

For example:

```text
2009-01-15 → 01
2009-05-20 → 05
2009-12-10 → 12
```
