# Part A - CSV Analysis

## Problem Statement

Build a Python command-line program that accepts a CSV file as input and performs basic data analysis.

The program should analyze the structure and contents of the CSV file and provide useful information about rows, columns, data types, missing values, numeric statistics, and frequently occurring values.

## Requirements

The program should:

1. Accept the CSV file path as a command-line argument.
2. Count the total number of rows.
3. Count the total number of columns.
4. Detect the data type of each column.
5. Count the number of missing values in each column.
6. Calculate the percentage of missing values in each column.
7. Calculate minimum, mean, and maximum values for numeric columns.
8. Display the most frequent values for text columns.
9. Support an optional `--top` argument to display the top N values.

## Part A Implementation

The program uses Python's standard library to read and analyze the CSV file.

### Numeric Value Detection

```python
def is_numeric(value):
    try:
        float(value)
        return True
    except ValueError:
        return False
```

This function checks whether a value can be converted into a numeric value.

### Column Type Detection

```python
def detect_type(values):
    non_empty_values = []

    for value in values:
        if value.strip() != "":
            non_empty_values.append(value)

    if len(non_empty_values) > 0:
        if all(is_numeric(value) for value in non_empty_values):
            return "numeric"

    return "text"
```

This function detects whether a column contains numeric or text data.

# Query 1 - Top 5 Customers by Total Spend

## Problem Statement

Find the five customers who have spent the most money.

## File

```text
sql/top_customers.sql
```

## SQL Code

```sql
SELECT
    Customer.CustomerId,
    Customer.FirstName || ' ' || Customer.LastName AS CustomerName,
    SUM(Invoice.Total) AS TotalSpend
FROM Customer
JOIN Invoice
    ON Customer.CustomerId = Invoice.CustomerId
GROUP BY Customer.CustomerId
ORDER BY TotalSpend DESC
LIMIT 5;
```

## Explanation

- `Customer` contains customer information.
- `Invoice` contains invoice information.
- `JOIN` connects customers with their invoices.
- `SUM(Invoice.Total)` calculates total spending.
- `GROUP BY` groups invoices for each customer.
- `ORDER BY TotalSpend DESC` sorts customers from highest to lowest spending.
- `LIMIT 5` returns the top five customers.

## How to Run

# Query 2 - Revenue by Country

## Problem Statement

Calculate the total revenue generated by each country and sort the results from highest to lowest revenue.

## File

```text
sql/revenue_by_country.sql
```

## SQL Code

```sql
SELECT
    Customer.Country,
    ROUND(SUM(Invoice.Total), 2) AS TotalRevenue
FROM Customer
JOIN Invoice
    ON Customer.CustomerId = Invoice.CustomerId
GROUP BY Customer.Country
ORDER BY TotalRevenue DESC;
```

## Explanation

- `Customer.Country` identifies the country.
- `Invoice.Total` contains invoice amounts.
- `SUM()` calculates total revenue.
- `GROUP BY Customer.Country` calculates revenue for each country.
- `ORDER BY TotalRevenue DESC` sorts countries by revenue.

## How to Run


# Query 3 - Top 10 Best-Selling Tracks

## Problem Statement

Find the ten tracks that have been sold in the highest quantities.

## File

```text
sql/best_selling_tracks.sql
```

## SQL Code

```sql
SELECT
    Track.TrackId,
    Track.Name AS TrackName,
    SUM(InvoiceLine.Quantity) AS QuantitySold
FROM Track
JOIN InvoiceLine
    ON Track.TrackId = InvoiceLine.TrackId
GROUP BY Track.TrackId
ORDER BY QuantitySold DESC
LIMIT 10;
```

## Explanation

- `Track` contains track information.
- `InvoiceLine` contains sales information.
- `JOIN` connects tracks with their sales.
- `SUM(InvoiceLine.Quantity)` calculates total quantity sold.
- `GROUP BY Track.TrackId` groups sales by track.
- `ORDER BY QuantitySold DESC` sorts tracks by quantity sold.
- `LIMIT 10` returns the top ten tracks.

## How to Run

# Query 4 - Monthly Revenue

## Problem Statement

Calculate the total revenue generated for each month during the selected year.

## File

```text
sql/monthly_revenue.sql
```

## SQL Code

```sql
SELECT
    strftime('%Y-%m', InvoiceDate) AS month,
    ROUND(SUM(Total), 2) AS revenue
FROM Invoice
WHERE InvoiceDate >= '2013-01-01'
  AND InvoiceDate < '2014-01-01'
GROUP BY month
ORDER BY month;
```

## Explanation

- `InvoiceDate` contains the invoice date.
- `strftime('%Y-%m', InvoiceDate)` extracts the year and month.
- `SUM(Total)` calculates total monthly revenue.
- `GROUP BY month` groups invoices month-wise.
- `ORDER BY month` displays the months chronologically.
- The query analyzes revenue for 2013.

## How to Run
